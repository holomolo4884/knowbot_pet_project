🧱 Неделя 1: Твёрдый синтаксический фундамент (4–10 мая)
Пн, 4 мая
Конспект (15 мин): Переменные и типы данных.
`let` — изменяемая, `const` — константа, `var` — устарела (не уходит из блока).
Примитивы: `string`, `number`, `boolean`, `null`, `undefined`, `symbol`, `bigint`.
Практика (1 час):
Функция `formatUser(name, age, city)`, возвращающая строку через шаблонные литералы.
Проверка `typeof` для каждого примитива, поймайте `typeof null === 'object'` (баг языка, запомнить).
Кейс с собеса: Чем `null` отличается от `undefined`? → Ответьте вслух и запишите.
Вт, 5 мая
Конспект (15 мин): Типы данных (продолжение) и строки.
Явное и неявное преобразование: `String()`, `Number()`, `Boolean()`.
Основные методы: `.slice()`, `.indexOf()`, `.includes()`, `.startsWith()`, `.toLowerCase()`.
Практика (1 час):
Функция `reverseString(str)` без `.reverse()` (через цикл или `.split('').reduce()`).
`capitalizeFirstLetter(str)` — первая буква заглавная.
Задача Codewars: 2 задачи 8 kyu на строки (прямо сейчас, не откладывая).
Ср, 6 мая
Конспект (15 мин): Условные операторы и операторы сравнения.
`==` vs `===` — всегда использовать тройное.
Тернарный оператор как замена простого `if/else`.
Логические `&&`, `||`, `??` (оператор нулевого слияния).
Практика (1 час):
`isEligibleForDiscount(age, hasCoupon)` — двойное условие через `&&`.
`getDiscount(isPremium)` — через тернарник вернуть 20 или 0.
Кейс с собеса: Что выведет `'5' == 5` и `'5' === 5`? Почему?
Чт, 7 мая
Конспект (15 мин): Циклы и итерация.
`for`, `while`, `do...while`.
Как избежать бесконечного цикла.
`break` (выйти) и `continue` (пропустить итерацию).
Практика (1 час):
Функция `factorial(n)` через `for`.
Вывести числа от 1 до 20, но если число кратно 5 — пропустить (`continue`).
Задача Codewars: 2 задачи 8 kyu на циклы.
Пт, 8 мая
Конспект (15 мин): Функции (погружение).
Function Declaration можно вызывать до объявления (hoisting).
Function Expression — нет.
Rest-параметры `...args` и оператор rest `...` (разные роли).
Практика (1 час):
`calculator(a, b, operator)` с `switch/case`.
`sumAll(...numbers)` — сумма произвольного количества аргументов.
Мини-тест пятницы: Объясните «как бы коллеге» разницу между Function Declaration и Expression.

⚙️ Неделя 2: Массивы, объекты и алгоритмическое мышление (11–17 мая)
Пн, 11 мая
Конспект: Массивы — создание и базовые мутирующие методы.
`push/pop` (конец), `shift/unshift` (начало).
`splice(index, deleteCount, ...items)` — универсальный «нож».
Практика:
`removeFromArray(arr, index)` — НЕ мутируя исходный (через `slice`).
`addToBeginning(arr, item)` — без мутации (через `[...]`).
Кейс с собеса: Чем отличаются методы, мутирующие массив, от немутирующих? Назовите по 3 примера.
Вт, 12 мая
Конспект: Функциональные методы массивов.
`.forEach()` — просто пройтись.
`.map()` — преобразовать каждый элемент.
`.filter()` — оставить только подходящие.
`.find()` — найти первый подходящий.
Практика (обязательно цепочками):
Дан массив чисел: `[1, 2, 3, 4, 5]`. Получите удвоенные нечетные числа.
Массив `users`. Получите массив имён пользователей старше 18.
Задача Codewars: 2 задачи 7 kyu на `.map` и `.filter`.
Ср, 13 мая
Конспект: Объекты — основа всего.
Точечная нотация и скобочная нотация (`obj['key']`).
Динамические ключи через `[variable]`.
Проверка свойства: `'key' in obj` vs `obj.hasOwnProperty()`.
Практика:
Объект `library` (массив книг). Метод `searchByAuthor(name)` через `.filter()`.
Функция `countProperties(obj)` — количество свойств через `Object.keys()`.
Кейс с собеса: В чём разница между точечной и скобочной нотацией? Когда использовать скобки?
Чт, 14 мая
Конспект: Деструктуризация.
Массивы: `const [a, b, ...rest] = arr`.
Объекты: `const { name, age } = user`.
Псевдонимы: `const { name: userName } = user`.
Практика:
Функция `getFullName({ firstName, lastName })`, возвращающая строку.
Поменять две переменные местами без третьей (через деструктуризацию массива).

Пт, 15 мая
Конспект:`this` и контекст вызова.
`this` в глобальном скоупе / в методе / в функции / у стрелочной функции.
Заимствование методов через `.call()` и `.apply()`.
`.bind()` для фиксации контекста.
Практика:
Объект `counter = { count: 0, increment() { this.count++ } }`. Вызовите метод, потом «потеряйте» контекст через присваивание в переменную, потом «привяжите» обратно `.bind()`.
Функция `borrowMethod(obj, methodName, args)`, вызывающая метод с контекстом через `.apply()`.
Мини-тест пятницы: Расскажите на камеру/диктофон, что такое `this` и 4 способа его определить.

🧠 Неделя 3: Глубинная механика JS и асинхронность (18–24 мая)
Пн, 18 мая
Конспект: Области видимости.
Глобальная, функциональная, блочная (`{}`).
`var` игнорирует блочную область (источник багов).
Hoisting: переменные `var` всплывают со значением `undefined`, функции — целиком.
Практика:
Код: `for(var i = 0; i < 3; i++) { setTimeout(() => console.log(i)) }`. Что выведет и почему? Почините на `let`.
Код: `console.log(a); var a = 5; console.log(b); let b = 10`. Что будет в каждом выводе? Почему?
Кейс с собеса: TDZ (Temporal Dead Zone) — что это и зачем?
Вт, 19 мая
Конспект: Замыкания (ключевая тема для собеса).
Функция «видит» переменные из внешней области В МОМЕНТ ВЫЗОВА, а не создания.
Практическое применение: каррирование, приватные переменные, фабрики функций.
Практика:
`createCounter()` — функция, возвращающая `{ increment, decrement, getValue }`. Внутренняя переменная `count` недоступна снаружи.
`multiplyBy(x)(y)` — каррированная функция умножения.
Задача дня: Напишите `once(fn)` — функция-обёртка, которая гарантирует, что `fn` выполнится только один раз (через замыкание).
Ср, 20 мая
Конспект: Прототипы и классы.
`__proto__` у каждого объекта, цепочка прототипов.
Классы = синтаксический сахар над функциями-конструкторами.
`extends`, `super`.
Практика: Класс  `Vehicle`  (свойство  `speed` , метод  `move` ). Класс  `Car extends Vehicle`  (свойство  `brand` , переопределённый  `move`  с вызовом `super.move()` ).
Проверьте: `car instanceof Vehicle` и `car instanceof Car`.
Кейс с собеса: Что такое прототипное наследование? Чем отличается от классического?
Чт, 21 мая
Конспект: Асинхронность: цикл событий (Event Loop).
Call Stack → Web API → Callback Queue → Event Loop.
Микрозадачи (Promise `.then`) — выполняются ПЕРЕД макрозадачами (`setTimeout`).
Практика:
Код: `console.log(1); setTimeout(() => console.log(2), 0); Promise.resolve().then(() => console.log(3)); console.log(4)`. Какой порядок вывода? Сначала ответьте, потом проверьте. Объясните себе вслух.
Напишите `delay(ms)`, возвращающую промис, который резолвится через `ms` миллисекунд.
Пт, 22 мая
Конспект: Промисы и цепочки.
`new Promise((resolve, reject) => ...)`.
`.then(onFulfilled, onRejected)` или лучше `.then().catch()`.
`Promise.all()` vs `Promise.allSettled()`.
Практика:
Симуляция загрузки данных: `fetchUser(id)` → затем `fetchOrders(userId)` → затем `fetchOrderDetails(orderId)`. Реализовать цепочкой промисов.
`Promise.all` для параллельной загрузки 3-х пользователей. Обработать случай, если один упал (`.catch` или `.allSettled`).
Мини-тест пятницы: Напишите на бумаге схему Event Loop и расшифруйте каждый блок.
Сб, 23 мая
Марафонский день (2.5 часа):
5 задач Codewars 6 kyu, включающих замыкания или асинхронность.
Перепишите вчерашнюю цепочку промисов на `async/await` с `try/catch`.
Реализуйте функцию `retry(fn, maxAttempts)`, которая перезапускает `fn` при ошибке до `maxAttempts` раз.
Вс, 24 мая

🧠 Неделя 3: Глубинная механика JS и асинхронность (18–24 мая)
Пн, 18 мая
Конспект: Области видимости.
Глобальная, функциональная, блочная (`{}`).
`var` игнорирует блочную область (источник багов).
Hoisting: переменные `var` всплывают со значением `undefined`, функции — целиком.
Практика:
Код: `for(var i = 0; i < 3; i++) { setTimeout(() => console.log(i)) }`. Что выведет и почему? Почините на `let`.
Код: `console.log(a); var a = 5; console.log(b); let b = 10`. Что будет в каждом выводе? Почему?
Кейс с собеса: TDZ (Temporal Dead Zone) — что это и зачем?

Конспект: Асинхронность: цикл событий (Event Loop).
Call Stack → Web API → Callback Queue → Event Loop.
Микрозадачи (Promise `.then`) — выполняются ПЕРЕД макрозадачами (`setTimeout`).
Практика:
Код: `console.log(1); setTimeout(() => console.log(2), 0); Promise.resolve().then(() => console.log(3)); console.log(4)`. Какой порядок вывода? Сначала ответьте, потом проверьте. Объясните себе вслух.
Напишите `delay(ms)`, возвращающую промис, который резолвится через `ms` миллисекунд.
